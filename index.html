📖 for vs while Loop

When to use which?

15 mins

for loop

# for loop — known count
for i in range(5):
    print(i)
▶ Run the code and observe the output:
When to use:
  • ✓ Known number of iterations
  • ✓ Iterating over items (list, range)
  • ✓ Counting / repeating fixed times

while loop

# while loop — condition-based
x = 0
while x < 5:
    print(x)
    x += 1
▶ Run the code and observe the output:
When to use:
  • ✓ Unknown number of iterations
  • ✓ Waiting for user input / condition
  • ✓ Keep running until something happens
Quick Check

Which loop should you use for "Find the password" (keep asking until correct)?

A) for loop
B) while loop
C) Either works
✅ B is correct!
We don't know how many attempts the user will need, so while is better. Use while password != "1234".

⚡ break vs continue

Skip iterations or exit loops completely

5 mins

continue — Skip this iteration

# Skip value 3

for i in range(5):
  if i == 3:
    continue
  print(i)
Output: 0, 1, 2, 4
Value 3 is SKIPPED, loop continues.

break — Exit loop completely

# Stop at value 3

for i in range(5):
  if i == 3:
    break
  print(i)
Output: 0, 1, 2
Loop STOPS at value 3. No more iterations.

Combined: while + continue + break

number = 0
while number < 10:
  number += 1
  if number == 3:
    continue  # skip 3
  if number == 8:
    break    # stop at 8
  print(number)

🔁 Nested Loops + break/continue

The core of this lesson — loops inside loops

20–25 mins

Basic Nested Loop

for i in range(3):  # outer loop
  for j in range(3): # inner loop
    print(i, j)
Visual:

continue in Nested Loop

for i in range(3):
  for j in range(3):
    if j == 1:
      continue # skip j=1
    print(i, j)
Question: Which values are skipped? Does it skip outer loop?
Answer: Only j=1 is skipped in each inner loop. The outer loop (i) keeps running! continue only affects the innermost loop it's in.

break in Nested Loop

for i in range(3):
  for j in range(3):
    if j == 1:
      break # stop inner
    print(i, j)
Question: Does break stop both loops?
Answer: No! break only stops the inner loop (j). The outer loop (i) continues!
To stop both loops, you need a flag variable (advanced).

Product Table with break

for i in range(1, 6):
  for j in range(1, 6):
    if i * j > 5:
      break
    print(i, j, i*j)
Try to predict the output before running!

🚀 Story: Planet Explorer Game

Story:
There are 2 planets.
Each planet has 4 checkpoints.
Astronaut collects energy points.

Rules:
  • • Checkpoint 2 is broken → use continue
  • • Checkpoint 4 is dangerous → use break
  • • Otherwise, add checkpoint number to energy
🎯 Challenge: Write the code to simulate this game!
Use nested for loops + continue + break.
energy = 0
for planet in range(1, 3):
  print("Landing on planet", planet)
  for checkpoint in range(1, 5):
    if checkpoint == 2:
      print("Checkpoint broken. Skip.")
      continue
    if checkpoint == 4:
      print("Danger! Stop planet.")
      break
    energy += checkpoint
    print("Collected", checkpoint, "points.")
  print("Leaving planet", planet)
print("Total energy:", energy)

While Loop Nested Version

row = 1
while row <= 3:
  col = 1
  while col <= 5:
    if col == 3:
      col += 1
      continue
    print(row, col)
    col += 1
  row += 1
Analogy: Like ordering food — everyone at a table needs to submit their order before the next table. Or unlocking game levels — you must pass level 1 tasks before level 2.
